PROJECT OVERVIEW:
This repository contains the corrected, fully responsive, modern web interface 
tailored for SRI GLOBAL MOPARTS PVT LTD. Built with pure HTML5, CSS3, 
and modular Vanilla JavaScript.

UPDATES & FIXES IN v2:
------------------------------------------------------------------------
1. About Section Content Alignment & Fluid Typography.
2. Full Responsive Grid system covering 320px to 1440px+ screens.
3. Component Category Image Paths Fixed (Suspension & Brake Parts restored).
4. Gallery Images & Lightbox Click Handlers fully connected.
5. Redesigned Contact Section with interactive Google Map embed.
6. ScrollSpy Active Menu Highlighting implemented in script.js.
7. Mobile Hamburger auto-close on link navigation.
8. Form submission validation & success message alert box.
